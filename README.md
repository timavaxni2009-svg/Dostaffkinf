## 🎯 О проекте

Dostaffkin — учебный pet-проект, имитирующий реальный сервис доставки. Приложение состоит из трёх страниц:

1. **`index.html`** — лендинг с описанием сервиса и переходом к основным действиям.
2. **`order.html`** — форма оформления доставки: выбор адресов, размера посылки, расчёт стоимости и отправка заявки.
3. **`track.html`** — отслеживание посылки по номеру с отображением текущего статуса доставки.

## ✨ Ключевые возможности

### Главная страница
- Премиальный дизайн с крупной типографикой
- Адаптивная верстка (мобильные, планшеты, десктоп)
- Плавные анимации появления блоков при прокрутке

### Оформление доставки
- **Интеграция с Яндекс.Картами** — интерактивная карта с метками адресов
- **Автодополнение адресов** через `ymaps.SuggestView`
- **Геокодирование** — преобразование адреса в координаты
- **Выбор размера посылки** из 6 тарифов (XS, S, M, L, XL, MAX)
- **Расчёт стоимости** — расстояние × тариф с учётом размеров
- **Валидация формы** — проверка имени и телефона перед отправкой
- **Генерация номера заказа** в формате `DST-XXXXXXXX`

### Отслеживание посылки
- Поиск заказа по номеру
- Отображение маршрута (откуда → куда)
- Список статусов: Создан → В пути → Готов к выдаче → Вручен
- Динамическое обновление статусов по времени

## 🛠️ Технологический стек

| Технология | Применение |
|---|---|
| **HTML5** | Семантическая разметка (header, main, nav, section, article) |
| **CSS3** | Flexbox, Grid, CSS-переменные, анимации, `backdrop-filter` |
| **JavaScript (ES6+)** | DOM API, события, асинхронность, localStorage |
| **Яндекс.Карты API 2.1** | Карта, геокодирование, автодополнение, построение маршрутов |
| **LocalStorage** | Хранение заказов между сессиями (в рамках демо) |
